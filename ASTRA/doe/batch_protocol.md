## Pre-Experiment Setup (15 minutes)

### Calibration
1. [ ] **Pressure standardization**
   - Place balance in horizontal position near work area
   - Practice applying 50g ± 5g (low pressure - genuinely light!)
   - Practice applying 200g ± 10g (high pressure - firm pressure)
   - Mark or memorize swab angle/hand position
   - **Literature context:** 50g = below volunteer minimum (~6.7 kPa on Q-tip)
   - **Literature context:** 200g = firm range (~27 kPa, in literature "firm" zone)

2. [ ] **ASTRA device setup**
   - Install fresh Q-tip
   - Test swabbing pattern on clean surface
   - Ensure consistent motion

3. [ ] **Prepare standards**
   - Confirm PETN+RDX standard concentration: 200 ng/µL
   - Calculate: 50µL × 200 ng/µL = 10,000 ng per surface
   - Verify standard is well-mixed

## Batch Workflow Overview

**IMPORTANT:** Surface test order is randomized within each batch. Always check the CSV file for the current batch to see which surface to test next (TestSequence column).

**Each batch follows this sequence:**
1. Spike 4 steel surfaces (2 min)
2. Dry 5 minutes
3. Test 4 steel surfaces **in order shown in CSV** (8 min)
4. Spike 4 ABS surfaces (2 min)
5. Dry 5 minutes
6. Test 4 ABS surfaces **in order shown in CSV** (8 min)
7. Clean all 8 surfaces (15 min)

**Repeat for Batches 1, 2, 3, 4**

**Tip:** Keep the CSV file (or checklist) open on a tablet/laptop during execution to reference the correct surface order for each batch.

## Troubleshooting

**Problem: Standard doesn't dry in 5 minutes**
- Solution: Extend drying time to 7-10 minutes
- Note in data sheet for all affected samples

**Problem: Pressure difficult to maintain**
- Solution: Re-practice on balance, adjust hand position
- Use consistent angle and grip throughout
- Note: 50g is very light (like resting 2 golf balls), 200g is firm but manageable

**Problem: Can't remember which surface to test next**
- Solution: Keep CSV file open on tablet/laptop during execution
- Refer to TestSequence column for correct order within each batch

**Problem: Surface contamination between tests**
- Solution: Extend cleaning time, add extra rinse step
- Verify dryness before re-spiking

**Problem: EtOH evaporates from swab during test**
- Solution: Apply EtOH immediately before swabbing
- Work more quickly (but still consistently)
